# LearnMate (G06): Evidence-Grounded Course AI Tutor

LearnMate is an M.Tech *Deep Learning Networks* project (CCA2/LCA-3). It is a local RAG tutor with three jobs:

1. Answer **only** from approved course material.
2. Cite passages that can be checked.
3. **Abstain** when the evidence is inadequate.

**Research question.** Can a calibrated gate decide when to answer better than a tuned reranker-score threshold (baseline B2)? The gate fuses a **trained sufficiency classifier** (DeBERTa-v3-base on SQuAD 2.0 + hard negatives) with **claim-level verification** (MiniCheck + NLI). Better means a lower AURC on an independently annotated course test set.

## Pipeline

```
d2l Markdown ─► section-aware chunks (≤400 tok, exact char provenance) ─► BM25 + bge-base FAISS ─► RRF ─► ms-marco CE rerank (top-5)
   ─► Qwen3-4B-Instruct-2507 answer with [C#] citations ─► citation validator
   ─► trained gate P(sufficient | q, passage) + MiniCheck support per sentence + NLI contradiction
   ─► logistic fusion (Platt-calibrated) ─► τ chosen by utility on cal split
   ─► state ∈ {sufficient, partial, insufficient, contradictory, system_error}
```

## Experiment commands

```bash
python -m eval.run --split squad-cal --stages all            # stages: retrieve generate gate gate_noHN b0 verify assemble
python -m eval.run --split course-cal --stages all
python -m eval.calibrate --squad-cal results/runs/squad-cal__clean --course-cal results/runs/course-cal__clean \
       --judgments data/annotations/judgments_cal.jsonl --course-dev-s4 results/runs/course-dev__S4
python -m eval.run --split course-test --condition S1 --stages all --require-prereg   # locked until preregistration is FROZEN
python -m eval.analyze --run results/runs/course-test__clean --judgments data/annotations/judgments_test.jsonl
```

## Course evaluation set
The two group members author the course evaluation items and blind-label each other's. The procedure is in [`annotation/GUIDELINES.md`](annotation/GUIDELINES.md): `python -m learnmate.annotation {validate,assign-splits,blind-sheet,kappa,judge-sheet,merge,freeze}`. No gold labels are generated by code.

## Reproducibility
- Every model is pinned by Hugging Face revision hash in `configs/base.yaml`.
- Seeds: 13 for training, 2026 for splits and bootstrap.
- Decoding is greedy, and every generation is cached under a key that includes the model revision, prompt hash and passage IDs.
- `data/manifests/` holds SHA-256 hashes of the corpus and SQuAD sources plus the exact split counts.
